1987 · Pandora

Into the Eagle's Nest

A cheat hidden in the high score table, a message for whoever took the tape apart, and a mission select that counts the wrong way.

01 · The cheat

Secret: type %MAGGOTS!& as your name

Get into the high score table, type those ten characters, and the next game cannot hurt you.

Show

The ten bytes at $6F31, drawn in the game's own alphabet. Each is a character's ASCII value with the top two bits removed, which is the form the name-entry screen leaves at $081F.

When the game builds a floor it calls $6F3B, which compares the ten characters of the name last typed on the high score screen with the ten bytes at $6F31. If every one matches it sets $603F, and while that byte is set three things change:

EffectWhere
Hits are never taken$63A6 turns the one routine that adds a hit away
A door key is always in hand$5BD1 writes 1 into the key count every frame
The ammunition is back to 99 every frame$5BB4

All ten characters are on the name-entry screen's own alphabet strip, so this is a cheat meant to be typed, not poked. Tested in the emulator: with the word in place a mission starts with $603F = 1 and a key in hand, and without it there is no key.

The check runs every time a floor is built, so the cheat lasts as long as the name does, and a new name on a later high score turns it off.

02 · The chests

Secret: a chest pays out one time in eight, and kills you one time in eight

The manual says a chest may hold something fragile, or explosives. It does not say how often.

Shoot

Press the button to shoot a chest. The dice are the game's own, read in order from the table at $8700.

OutcomeChance in the codeShots so far
EMPTY!3 in 40
SOME JEWELS. (4000 points)1 in 80
FOOL!....EXPLOSIVES. (the game ends)1 in 80

The decision at $5598, run here as the game runs it, on the game's own random numbers.

Shooting a closed chest goes to $5598, which takes the next number from the table of random numbers and compares it with $C0. Three values in four are below it, and the chest is empty. On the fourth it takes a second number and compares it with $80: half of those give jewels, worth 4000, and the other half give explosives.

Explosives set $02D3 to 1, which is the explosion at $5BDD: the border and the background run through seventeen colours, five times over, and then the game is over. There is no warning and nothing to be done about it, which is what the message calls the player.

So a chest is worth shooting only if 4000 points are worth a one-in-eight chance of ending the game. The tip in the manual, "Only shoot at a known target", is the game telling you the odds without giving them.

03 · The loader

Secret: the tape loader says hello

The game's own loader carries a message for whoever pulled the tape apart.

WILD SAVE (C) INTERCEPTOR MICROS 1987 WRITTEN BY ANDREW CHALLIS JANUARY 1987 HELLO HACKER I HOPE YOU HAVE FUN WITH THIS LOADER

At $033C, in the cassette buffer, in plain ASCII. It is not drawn on any screen: it sits in the loader's own work space and the game never reads it.

The address is the C64's tape buffer, which is where a loader lives while it is reading. Wild Save was Interceptor Micros's tape system, and this says Challis wrote the game's copy of it himself in January 1987, a few months before the game came out.

Whoever left it expected the tape to be taken apart, and left a greeting where only that reader would find it.

04 · The mission select

Bug: MISSION 1 blows up the castle

The manual says mission four brings the castle down. On the screen it is mission one.

Taken in the emulator, one after the other: three pushes down and fire.

The game keeps the mission number in $0836, and the briefing at $1E3F reads it: 4 orders the castle blown up and anything else orders a prisoner rescued. The digit on the screen is not that number. $1DBE draws five minus it, so the mission the game calls 4 is the one the screen calls 1.

The manual was written for the American disk release, where the missions are numbered the way it describes. On this tape the screen counts the other way, and a player following the manual starts with the demolition.

05 · The guards

Secret: no guard in the game ever fires

The manual warns that the soldiers shoot and do great damage. They do not shoot at all.

What writes the hit count at $02C6What it does
$4058, $4077clears it, and puts back what the last mission left
$4F23cold food: takes $10 off it
$4FA2first aid: clears it
$63B2inside $639F, the one routine that adds a hit

Every instruction in the game that can touch the hit count, found with the references search over every opcode and every index. $639F has four callers, and all four are the branches of the guards' movement where the tile ahead holds the player.

A guard hurts the player by walking into him, one hit at a time, and nothing else in the game hurts him at all. Fifty hits end the mission, which is the number the manual gives.

Standing still in a room with two guards for two minutes, with a counter on $639F, left the hit count at zero: the guards keep to their own part of the floor. The damage comes from walking into them.

06 · The dice

Secret: the sound chip is the random number generator

The game rolls its dice once, at start-up, out of the SID's noise.

The 256 bytes at $8700 as the game built them, one column a byte. Drawn from a snapshot of play, not from the listing: the table does not exist until the game runs.

$67CA sets voice three to noise at the highest frequency it can hold, reads the voice's own oscillator output at $D41B 256 times, writes what it reads into $8700, and silences the voice again. From then on $67F3 steps an index through those 256 bytes, round and round, and that is every random number the game ever uses.

Reading the chip's noise is a common trick on the C64, and most games that use it read it afresh each time they need a number. Reading it 256 times at the start and keeping the answers costs a page of memory and makes every game identical from the same starting point.

07 · The spare tiles

Secret: 999 bytes of castle nothing draws

The tape loads 125 characters' worth of tiles that no instruction reaches.

The bytes from $8C00 to $8FE6, drawn as 8 by 8 characters. Searched for a reader with the references search, by name, as a pointer and through an index: there is none.

They are shaped like the walls and floors the game draws from, and they are not the set it uses, which is at $2000. The manual promises a second castle, harder than the first, once the first has been destroyed. Nothing in this version builds one: the map builder always reads the same four descriptions.

Whether these are that second castle's tiles is open. They are the only candidate in the image, and nothing reads them.
