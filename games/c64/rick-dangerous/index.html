Commodore 64 · 1989 · Firebird

Rick Dangerous

Core Design's platform game of traps, sticks and dynamite. Its Hall of Fame hides two names that change the game: one turns on a cheat and the other a level select.

01 · The game

An explorer in 1945

Rick Dangerous is an explorer in 1945, crashed in the Amazon among the Goolu tribe. The game takes him through four places: a cave in South America, a pyramid in Egypt, Schwarzendumpf Castle in Europe, and a secret missile base aimed at London. Each is a single tall map of rooms, which Rick crosses by walking, jumping, climbing and crawling.

Almost everything in a room can kill him: the tribesmen and guards who walk the rooms, and above all the traps, which the manual declines to explain. Rick carries a pistol, a stick for jabbing, and dynamite, and he starts with six lives, six bullets and six sticks. A touch from an enemy or a trap costs a life, and he starts again where he entered the room.

The title screen, and the first room of the cave. The panel shows the score, the bullets, the dynamite and the lives as hats.

02 · One frame

What the game sees in a room

The picture below is drawn by this page from the memory of one frame of play, recorded in the emulator: the screen, the character set and the video chip's registers as they change during the frame. Every one of its 104,448 pixels matches the emulator's own picture.

Drawn by the site's C64 renderer from the recorded frame, pixel for pixel the emulator's picture. The overlay takes each tile's code from the screen and looks it up the way $4081 does, with the eight codes of graphics set 0 from $185B.

The room is made of characters, and the game decides what each one is by its code alone. Eight codes in zero page ($38-$3F, copied from $185B for each graphics set) mark where each kind begins: background first, then ladders, deadly tiles, scenery that stands in front of Rick, platforms, floors, solid walls, and the tops of ladders. $4081 turns those eight numbers into a table of 256 flags at $0600, and every collision test reads it. The tile graphics only have to be kept in that order.

03 · Secret

Secret: two names change the game

A score good enough for the Hall of Fame lets the player spell a name of up to ten letters with the joystick. The routine at $2146 then compares the name with two words kept at $21B8. BBOOIINNGG turns on two cheat keys ($53): 2 fills the bullets, the dynamite and the lives back to six, and C= jumps to the next level. FLUFOMATIC ($37) turns the title screen into a level select, offering every level reached so far ($51).

Before either check, $2103 looks for eleven rude words in the name and writes SNIGGER over any name that holds one. The search is looser than it looks: it takes each word's letters in order anywhere in the first seven letters, with other letters between them. Type a name to see what the Hall of Fame keeps.

The level select, after FLUFOMATIC, with all four levels reached. The name box runs a port of $2103 and $2146, checked against the game's own routines on 3,000 names in the kit's 6502 simulator (test_names.js).

The level select has one more condition. A game started from it does not show the ending: $23A0 skips the story screen for the fifth "level" when the start was chosen ($52). A player who took the shortcut finishes on GAME OVER.

04 · Music

Music: seven tunes by Dave Pridmore

A tune plays on each story screen before a level, on the ending, on the title and Hall of Fame, and on GAME OVER. None plays during play: while a tune runs, the sound effects and Rick's footsteps are silent ($4F86).

The game's own music player, its code ($5042-$5730) and the tunes' data ($5732-$5F8D) as the listing holds them, run on a small 6502 core in this page once a frame, through the site's model of the SID. test_music.js compares every SID write of every frame of all seven tunes with the same code run in the kit's simulator: 117,097 writes. The tunes do not use the filter.

Each tune has a header of three addresses at $5732, one track list a voice. A track list is a run of pattern numbers with a few commands mixed in (transpose, repeat, change an instrument); a pattern is notes and their lengths, rests, and changes of instrument, arpeggio and slide. Tunes 5 and 6 leave voice 3 alone.

05 · The rooms

Each level is one tall map

A level is a column of map rows, eight bytes each, from $9200 to $A5BF. Each byte is the number of a block, and each of the 256 blocks at $8200 is four rows of four tiles. So a map row is 32 tiles across, the width of the play area, and four tiles deep. The screen shows six map rows; when Rick climbs near the top or the bottom, the view scrolls two map rows (64 pixels) as eight shifts of one row ($3018, $30A3), each built on the hidden screen and swapped in.

The Maps tab draws all four levels from these bytes. Levels 1 and 2 use one tile set and levels 3 and 4 another; $1911 swaps them, exchanging 2 KB of graphics between $7000 and the RAM under the I/O chips.

06 · Traps

Every trap says what sets it off

Each object in a room has a record of five bytes in the object lists ($A5C0): where it is, its type, and a byte of flags. For a trap, four of the flags say what sets it off: Rick walking into its zone, the stick, a bullet, or an explosion ($1A72). One more makes it deadly to touch while it moves and another while it waits, and one pays 1000 points and removes it when its movement ends.

Counted by this page from the object lists in the listing: the records of types 24 to 70, the traps, in the rooms of each level.

That is why the manual warns that the gun is often a trigger rather than a weapon. A trap with only the bullet flag goes off at nothing but a shot.

07 · Sprites

Rick walks behind the scenery

A C64 sprite can be set behind the background, but then it is behind every foreground pixel on the screen at once, and Rick has to pass behind some tiles and in front of others. So Rick Dangerous builds his picture again every frame ($0F83): it takes his 64-byte frame and ANDs it with a mask made from the tiles behind him ($1052), clearing every pixel where a tile of the "in front" kind stands. The dynamite and up to three enemies get the same treatment. The finished pictures go into one of two sets of buffers, $C800 or $CA00, by turns, so the video chip never shows a half-drawn one.

The rest of the objects share six hardware sprites. $3559 sorts them by height every frame and, when there are more than six, moves sprites 2 to 5 down the screen during the frame to show up to four more. The bullet is not a sprite at all: $2ABA writes a character into the screen, keeping the one it covers, and moves it eight pixels a step.

08 · Controls

Secret: a second joystick can end the game

The manual gives the up-arrow key for quitting. The game reads ← instead: $0A95 tests one bit of the keyboard, and pressing ← ends the game. That bit is shared with joystick port 1, because the game never changes which keyboard row it reads ($DC00 stays at $7F). A joystick left in port 1 and pushed down ends the game too, and pushed right it is the cheat's 2 key.

Run/Stop, on the same keyboard row, pauses the game until it is pressed again ($40E0).

09 · The Hall of Fame

Secret: the Hall of Fame can change at power-on

At power-on, $226A reads the line the video chip is drawing and uses it as a random number. When the line's top bit is set and its three low bits are not all zero, about seven times in sixteen, it copies NOBBY or JEZEBEL ($2368) over one of the first seven names. The names are stored column by column ($2318): the first letters of all eight names, then the second letters, and so on.

The Hall of Fame the game starts on. JEZEBEL is one of the two names $226A can add.

10 · Leftovers

A line of the source code, loaded with the game

The sprite multiplexer's buffers at $3963 are overwritten in the first frame, but before that they hold plain text: RICK_MASK,Y, a line break, !124, a tab and S. It is a fragment of the game's own assembler source, left in memory on the developers' machine when the game was saved.

Other things the finished game never uses are still in it: a collision test nothing calls ($1CB1), a memory swap ($2524), and a routine that writes a byte as eight binary digits ($414E). Holding SPACE while a room is built copies the map rows above the screen over its bottom eight rows ($2FD5). The start-up calls $4108 once to build the object-type tables and then writes an LDA over its own JSR ($0864), so the call never happens again.

11 · The tape

One load

The cassette loads once. A turbo loader puts up NOW LOADING ... RICK DANGEROUS and reads the whole game into memory, all four levels, the ending's text and every tune; nothing is loaded again. The game's first instruction is at $0810.
