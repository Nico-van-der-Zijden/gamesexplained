The game is a 6502 program in eight parts, loaded from tape as the war needs them: the script that loads and calls the others, the title, the menu, the map, the battle, the fort, the train and the ending. The port is the same program written again in JavaScript, one function for each routine the game calls, 606 in all, reading and writing the game's variables at the game's own addresses, its self-modified operands included. The page runs only the port: the game's code is in the tests, as the original the port is held to.
